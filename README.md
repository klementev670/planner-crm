# Планировщик 2026–2027 — веб-CRM

Веб-версия твоего Tkinter-планировщика: цели, канбан, помодоро, ежедневник,
таймлайн и статистика. Данные хранятся в Supabase (Postgres), поэтому ПК и
телефон видят одни и те же задачи в реальном времени. Устанавливается на
телефон как приложение (PWA) и умеет слать пуш-напоминания о дедлайнах целей.

## 1. Supabase (база данных, бесплатно)

1. Зайди на supabase.com → New project.
2. В SQL Editor вставь и выполни содержимое файла `supabase/schema.sql`.
3. В Settings → API скопируй `Project URL`, `anon public key` и
   `service_role key` — они пойдут в переменные окружения.

## 2. Локальный запуск

```bash
npm install
cp .env.example .env.local   # заполни значениями из Supabase
npm run generate-vapid       # вставь выведенные ключи в .env.local
npm run dev
```

Открой http://localhost:3000, введи код доступа (`APP_PASSCODE` из `.env.local`).

## 3. Деплой на Vercel (бесплатно, доступ с телефона)

1. Залей проект в GitHub-репозиторий.
2. На vercel.com → Add New Project → выбери репозиторий.
3. В Environment Variables добавь все переменные из `.env.example`
   (те же значения, что в `.env.local`, плюс `CRON_SECRET` — любая случайная строка).
4. Deploy. Vercel сам подхватит `vercel.json` и включит ежедневный cron
   (проверка дедлайнов и отправка пуш-уведомлений в 06:00 UTC — поменяй
   расписание в `vercel.json`, если нужно другое время).

## 4. Установка на телефон и ПК

- **Android (Chrome):** открой сайт → меню (⋮) → «Установить приложение».
- **iPhone (Safari):** открой сайт → «Поделиться» → «На экран «Домой»».
- **ПК (Chrome/Edge):** иконка «Установить» в адресной строке.

После установки приложение открывается как обычное, работает офлайн для
уже загруженных страниц и может присылать пуш-уведомления о дедлайнах —
для этого нажми «🔔 Включить напоминания» в боковом меню и разреши уведомления.

## Структура

- `src/app/*` — страницы (Обзор, Цели, Канбан, Помодоро, День, Таймлайн, Статистика)
- `src/app/api/*` — серверные обработчики (CRUD + push + cron)
- `src/lib/useRealtimeList.ts` — общий хук: REST-запрос + подписка на
  Supabase Realtime, за счёт этого изменения на одном устройстве сразу
  видны на другом
- `public/sw.js` — service worker (офлайн-кэш + push)
- `supabase/schema.sql` — схема БД
